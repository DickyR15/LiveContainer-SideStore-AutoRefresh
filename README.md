# LiveContainer + SideStore AutoRefresh

LiveContainer + SideStore AutoRefresh 整合、修復與測試專案。

## 基準
- LiveContainer 3.8.10
- Embedded SideStore 0.7.0
- NRG-Wardog Unified v3.1.0 作為外部比較基準

## 目標
- 手動 Refresh / Refresh All
- iOS 27 App Intent
- Apple Session / Authentication
- ADI / adi.pb provisioning
- 背景 AutoRefresh

## 測試版本命名
每次建置的 IPA 使用 GitHub Actions Run Number，例如 `LiveContainer-SideStore-AutoRefresh-v236.ipa`。
